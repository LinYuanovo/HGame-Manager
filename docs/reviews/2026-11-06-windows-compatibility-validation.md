## 原生发现并修复的问题

`windows/runner/flutter_window.cpp` 含 UTF-8 中文注释，MSVC 默认按代码页 936 解读，触发 C4819，并因 `/WX` 升为 C2220；部分注释被误解析后产生 C2065 等错误。Linux 分析不会检查这条 C++ 编译链。

在 `windows/runner/CMakeLists.txt:22` 对应用目标增加 `/utf-8`，随后真实 Debug 构建和运行通过。未关闭 `/WX`，也没有改动中文注释或原生浮窗注册行为。

NuGet 最初未在 PATH 中，属于本次宿主环境准备问题：使用任务专用工具目录解决，没有修改系统 PATH。WebView 插件仍有自身的 CMake/编译警告，未为此扩展修改范围。
