## 审阅修复

| 问题与触发方式 | 修复与验证 |
|---|---|
| 中文输入法先更新组合文字，再仅清除组合范围时，正文搜索未收到最后一次提交。 | 监听完整编辑值，在文字变化或组合提交时搜索；移动光标不会重复搜索。离线用例已复现修复前的漏搜。 |
| 鼠标悬停后拖动评分，实际分值变化但星级仍显示旧预览。 | 确认与拖动时清除悬停预览，并接收拖动开始位置。离线用例核对实际分值与五颗实星。 |
| 列表补位时画面已经移动，点击区域却停在最终布局位置，导致点击落空。 | 位移同时作用于点击检测。离线用例在运动中点击当前绘制的按钮。 |
| 无限滚动浏览后切换海报与列表，当前游戏离开视口。 | 切换完成后按游戏 ID 定位目标。离线用例在第 19 款游戏处双向切换并检查可见性。 |
| 多选模式中聚焦游戏后按回车直接打开详情。 | 回车遵守多选状态，Shift+回车沿用范围选择。离线用例核对勾选结果及详情未打开。 |
| 攻略甲正在下载图片时改选乙，甲的迟到写入可能覆盖乙的同名图片；打开搜索时还会提前删除已保存配图。 | 每次选择使用独立文件名，过期请求停止写入；打开搜索保留已保存图片。Windows 用本机 HTTP 服务验证乱序响应后的当前图片和旧图片内容。 |
| 分类取消收藏等待写入时仍能再次提交，失败后的按钮也可能保留禁用状态。 | 同步锁定目标，完成或失败后重建按钮状态。离线用例连续调用同一操作并模拟写入失败。 |
| 恢复默认热键未进入保存状态，可以与录制或再次重置并发；写入异常未在当前项反馈。 | 重置期间锁定相关按钮，捕获错误并恢复可操作状态。离线用例覆盖重复触发及失败恢复。 |
