# DLsite 简介与图片缺失排查

日期：2026-11-14

## 原因

当前 DLsite 作品页已采用新版服务端 HTML。原解析器只读取 `[itemprop="description"]` 和 `.product-slider-data div[data-src]`，真实页面中这两种节点都已不存在。因此简介为空，图片列表只剩 `og:image` 封面。

新版简介分散在 `.c-productContent` 区块，画廊原图位于 `#work_visual .slider_body img`。画廊控制栏另有同一批缩略图，不能把全部 `#work_visual img` 直接作为下载列表。厂商与作品标签也改用 `.c-productInfo__makerName` 和 `.c-productInfo__item` 中的标签链接。

## 真实页面复现

使用独立 `playwright-cli` 会话访问公开页面，读取导航的 HTTP 响应 HTML。随后以应用现有 User-Agent、Cookie 和 Accept 请求头重新访问，三件作品均返回 HTTP 200，结果一致。没有使用用户登录资料。

| 作品 | 旧版简介节点 | 旧版画廊节点 | 新版简介区块 | 画廊原图 | 正文图 | 合计去重图片 |
|------|--------------|--------------|--------------|----------|--------|--------------|
| [RJ01169914](https://www.dlsite.com/maniax/work/=/product_id/RJ01169914.html/) | 0 | 0 | 7 | 11 | 6 | 17 |
| [RJ01263980](https://www.dlsite.com/maniax/work/=/product_id/RJ01263980.html/) | 0 | 0 | 7 | 7 | 6 | 13 |
| [RJ259819](https://www.dlsite.com/maniax/work/=/product_id/RJ259819.html/) | 0 | 0 | 1 | 3 | 0 | 3 |

旧编号作品也已迁为新版页面，不能按 RJ 编号长度选择解析分支。旧版结构通过内嵌同构样本验证兼容性。

## 修复

- `DlsiteParser` 同时支持旧版简介与新版全部简介区块，保留图文顺序和富文本结构。
- 图片使用旧版画廊数据或新版画廊原图，再合并正文图并去重；控制栏缩略图和画廊视频不进入图片列表。
- 简介图统一为绝对 URL，与下载列表一致，便于下载后替换为本地图片引用。
- 补齐新版厂商与作品标签选择器。
- `DlsiteService.fetchCoverUrl` 复用同一个作品解析流程。

## 入口一致性

快速刮削、重新刮削、刮削中心的 DLsite 分支，以及单个/批量添加的 DLsite ID 或搜索导入，最终都通过 `DlsiteService.fetchById` 和共享 `DlsiteParser` 获取资料，因此同一修复对五种入口生效。

## 验证材料

- 既有 `test/dlsite_parser_test.dart` 更新为可独立运行的内嵌旧版/新版结构测试，覆盖正文、多图、去重、缩略图排除、视频排除、本地引用替换及解析器复用。
- 三件真实响应 HTML 用于临时解析验收，记录字段长度和数量；验收结束后清理响应 HTML 和临时测试脚本。
- Flutter/Dart 测试由主代理串行运行，最终结果与原生应用验收统一记录在本任务交付报告。

页面结构排查和解析验证不能代表下载成功、用户所用网络通畅或所有 DLsite 作品均有简介；这些边界以最终实机报告为准。

## Issue #17 备用数据补强与验收

根据 [远程反馈 #17](https://github.com/LinYuanovo/HGame-Manager/issues/17) 补齐 `.work_slider` 原图及 `dd.c-productInfo__value` 标签容器，并支持当前作品的 `Product` JSON-LD 作为字段兜底。完整 DOM 正文优先；只有章节标题或图片时补入结构化短简介，原有图文仍保留。结构化图片与画廊、正文图片去重合并，不固定图片数量。

作品匹配使用 `sku`、作品 ID 与 `offers.url` 等身份字段。支持独立对象、数组和 `@graph`；多作品且身份或标题无法对应时不猜测。损坏脚本不影响后续有效脚本和 DOM。图集排除 `/resize/`、尺寸缩略图及视频，唯一可用的合法 OG 缩略封面仍保留。

| --- | ---: | ---: | ---: |
| RJ01169914 | 17 | 11 | 107 |
| RJ01263980 | 13 | 7 | 46 |

22 项内嵌新旧结构及字段兜底回归通过，3 项真实响应降级解析通过。Windows 原生应用再次实时请求上述三件作品，均取得非空简介及多图；RJ259819 的备用短简介和 3 张真实图片经共享确认保存流程落库、落盘，元数据包含已刮削标识。真实样本只出现独立 Product 对象，数组与 `@graph` 属于回归模拟验证。

正文长度及区块数会随语言与页面内容变化，验收按实际返回检查，不依赖固定区块数量。所有响应样本、临时测试入口和日志在完成后清理，最终证据汇总于 [任务验证报告](./scrape-review-tags-dlsite-2026-11-14.md)。
