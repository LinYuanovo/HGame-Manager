## 审阅修复

1. **翻译会改变目录分类。** 分类器依赖 `RPG`、`ACT` 等原标签特征，标签翻译后可能落入其他目录。标签与系列中的常用类型代码保持原样；目录整理读取已保存原文进行分类，使 `Action` 翻译为“动作”后仍进入原来的 `ACT` 目录。原生用例覆盖五种共享流程、真实 SQLite 和实际目录移动。
2. **关闭详情后同路径封面仍显示旧图片。** 原实现只驱逐图片缓存，现有 `Image` 控件仍持有旧图像流。原生测试把红色封面覆盖成绿色后，读取到的像素仍为 `[239, 68, 68, 255]`，实际复现失败。修复为等待驱逐结束后更新图片控件标识，触发重新解码。
3. **翻译设置的保存按钮未跟随深色前景值。** 两分支整合后，背景使用新浅色主色，前景却仍由旧接口固定返回白色。改用 `getOnPrimaryColor`；原生测试分别检查浅色和深色的实际按钮样式。
4. **翻译请求未接入新诊断日志。** 补上完成、HTTP 错误状态及回退失败类型。记录服务名、数量和错误类型，避免把请求内容、模型原始响应及密钥写入日志。原生测试解压诊断包核对翻译与刮削记录，以及凭据和 URL 查询参数过滤。
