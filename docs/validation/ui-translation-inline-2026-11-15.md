# 翻译设置与界面令牌检查

日期：2026-11-15。

## 实现

- 刮削确认的「全选」「清空选择」「选择放弃和失败项」采用统一描边按钮，字号、圆角、间距和高度使用项目令牌，字体继承当前应用设置。
- 翻译开关直接显示在「设置 → 刮削 → 元信息自动翻译」卡片。开启后展开服务选择，选择 LLM 时显示接口、模型、密钥和提示词；展开时长与曲线使用已有动效令牌，并尊重系统减少动画设置。
- 关闭开关、切换服务或设置分类保留本次编辑草稿；点击设置页「保存」统一持久化，取消关闭不保存。启用 LLM 时验证接口和模型。
- 连接测试仅测试当前服务，使用当前填写的配置和提示词。客户端创建、请求和响应处理合计最多 20 秒；界面显示「正在测试连接，最多等待 20 秒…」，到时显示超时结果并恢复按钮。
- 切换配置或关闭设置时结束测试请求，迟到响应不会覆盖新状态。正式刮削翻译的超时和兜底策略保持现有行为。

## 硬编码检查

检查范围为 1.5.7 相对远程主分支 `f5162cf` 的 UI 改动，以及当前完整 `lib/ui` 和 `lib/main.dart` 的颜色、字号、字体、图标、间距与圆角规则。

| 项目 | 结果 |
| --- | --- |
| 颜色、字号、图标、常用间距和圆角 | 扩展静态扫描通过，采用 `AppTheme`、`GlassConstants` 与 `LayoutConstants` |
| 按钮和菜单字体 | 修复独立 `TextStyle` 覆盖主题字体的问题；标准按钮标签和弹出菜单继承应用字体 |
| 关联控件 | 同步修正批量导入、详情标签操作、标签弹窗及设置下拉框的字体继承 |
| 本次改动的描边、进度线宽和紧凑行高 | 对齐已有间距令牌及共享行高令牌 |
| 字号预览 | 预览独立显示，修复自定义字体和 1.25 倍文字缩放时的横向溢出 |
| 字体名称 | 主题默认字体与字体选择器的字体预览保留明确字体名，属于字体定义与预览，不覆盖普通界面字体 |
| 其他数值 | 既有窗口尺寸、媒体尺寸、字号选择范围、网络超时和图片解码宽度按实际用途区分，不作为普通样式字面量批量替换 |

新增扫描会阻止控件样式直接以 `textStyle: TextStyle(...)` 覆盖主题字体，并检查普通 UI 中的固定字体名称；运行时测试检查实际 `DefaultTextStyle`，避免只检查数字令牌而遗漏字体继承。
