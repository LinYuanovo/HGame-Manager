# 动效分支逐页与设计令牌审阅

审阅以 `codex/motion-loading` 的 `366ee59` 和工作树原有的 23 个未提交文件为基线。应用按单用户 Windows 桌面场景检查。主窗口有八个导航入口，设置通过弹窗打开。代码扫描包含 `lib/main.dart`、页面、共享组件、主题和攻略浮窗。

## 规范与验收

- 本轮迁移了 79 处页面内 `styleFrom`。普通按钮使用主题默认值，带语义的按钮使用 `AppButtonStyles`。`AppTypography` 管理字族、字重、行高、按钮标签、弹窗标题和字体预览。
- 静态测试扫描主题以外的颜色、字号、图标、常用间距、圆角、字重、行高、按钮样式和局部字族。组件测试检查浅深色中的实际字体继承、四类按钮反馈、语义实色按钮文字对比度和列表重试。
- 离线回归共 281 项通过。Windows 集成用隔离样本库渲染主路由、六个设置分区、子窗、各种加载结果和攻略浮窗。截图按界面状态生成，人工抽看两种主题的导航、设置管理、导入、详情、图片与存档界面。
- 文件选取器、真实网络账户、系统读屏、跨显示器刷新率仍需实机专项验收。窗口截图和模拟进度只证明相应宿主界面状态。页面布局宽高、图片比例、业务等待时间仍由相应组件负责。
- 最终版本通过 2 项 Windows 原生测试，共 166 个界面状态和 166 张截图。错误态断言覆盖六个主列表及分类、收藏的第二个标签页。本机窗口报告 165 Hz，800 ms 探针在 806 ms 收束。静态分析报告 0 个错误、19 个警告、433 条提示，退出码为 1。
- 分支与当时的 `master` 分叉后，主线已有 22 个独有提交，包括翻译设置、详情页和刮削流程更新。合并时需把此处的主题行为应用到主线现有入口。
