# 动效与加载逐页审阅

日期：2026-11-10。分支：`codex/motion-loading`。本轮审阅基线：`8942e01`。

按 Windows 单用户桌面应用检查页面、共享组件及异步调用。沿用分支已有的短淡入、轻微位移、首屏交错、主题颜色与系统减少动效规则。

## 修正结果

1. **攻略搜索防止重复请求**：按钮禁用后，重新聚焦输入框并回车仍能发起第二个请求。现在回调入口检查忙碌状态，搜索期间固定来源并锁定输入，保证显示内容对应同一次请求。
2. **攻略正文提供持续反馈**：选择结果后，获取正文及图片期间保留搜索结果、显示忙碌提示并禁用重复选择；失败后恢复操作。窗口开始关闭后到达的结果不会再弹出攻略选择窗口或关闭下一层页面。
3. **图片处理保留已知内容**：保存或添加图片时保留已有图片网格、位置和封面选择，暂时禁用网格操作并显示处理提示。空图片区域才使用骨架。窗口关闭后，保存回调不再访问已销毁的界面或调用 `setState`。
4. **本地存档等待与失败恢复**：搜索和下载存档期间按钮显示持续忙碌反馈。读取备份列表失败时结束骨架，展示错误和重试入口，避免永久等待。
5. **云端备份操作互斥**：下载、恢复和删除期间显示处理状态，禁用刷新及其他备份操作；结束或失败后恢复。删除成功后的列表刷新也包含在忙碌周期中。
6. **刮削扫描状态明确**：扫描尚未返回游戏时显示扫描骨架与不确定进度；结果返回后再进入列表或空态。

前三个针对性失败用例在修复前分别复现重复请求两次、正文获取缺少反馈、图片保存后触发 `setState() called after dispose()`。
