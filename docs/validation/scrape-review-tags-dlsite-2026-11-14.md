## 实现结果

### 批量确认

刮削中心和 Steam/DLsite 批量添加先抓候选资料，之后进入独立确认表单。表单对照原游戏与候选标题，展示来源、简介、标签和图片；支持逐项保留或放弃、多选处理、保存已保留结果，以及把所选游戏移动到指定文件夹。

放弃不应用候选资料。已保留结果保存后可移动；失败和放弃项也可集中移动，保持每个游戏自己的子目录。抓取失败可修改来源或关键词后重试，其他待确认结果保持原样。同路径有效待确认结果会复用。

待确认列表在本次应用运行期间保留，可关闭表单或切换页面后继续查看；退出应用后需重新抓取。确认保存、目录重命名与移动分别采用共享服务。图片缺失或元数据写入失败会恢复原资料，恢复未完成时保留有原相对路径的恢复文件并显示明确状态。刮削只更新元数据字段，保存和恢复均保留同期新增的游玩时长。

目录搬运把路径、正文引用、图片、启动器和存档路径作为一个数据库事务更新，元数据文件失败和真实事务提交失败均回滚。现有自动重命名、分类整理也复用该流程。

### 自定义标签

游戏详情资料卡增加「编辑标签」。支持选择已有标签、连续输入新标签、去重、移除和取消；全局资料编辑共用一致保存服务。数据库及 `HGMDatas/metadata.json` 同步保存，失败时回滚，重新扫描会同步普通标签增删。旧 JSON 缺少 `tags` 字段时保留已有关系。

原问题包括：入口仅隐藏在全局编辑模式；保存只改数据库关系，未写回 JSON；启动应用只读取数据库，不重新扫描。手改 JSON 后应点击游戏页「刷新」。重新刮削仍按站点资料替换标签。已删除本体的通关游戏可继续保存标签未改变的资料，并同步通关备份。
