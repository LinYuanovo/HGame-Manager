## 处理规则

- 解析真实受限区块及限定提示节点，受限结果携带 `isDlsiteUserOnly`；写盘使用 `dlsite_restriction: user_only`。
- 过滤图库、结构化数据、封面及正文中的 DLsite 占位图。普通页面仍使用现有正文和多图解析。
- 受限页通过公开商品 API 补充封面、样图、作品类型和标签。只有返回结构、作品身份及必要公开字段满足条件时才产生候选；失败写入警告并返回空结果。
- 受限正文不由摘要替代。重新刮削保留原有简介和 HTML，正常完整重刮后移除受限标记。
- 旧正文引用的编号图片在更新前复制为已支持的 UUID 文件名，同步修改引用；覆盖仅 HTML 引用、重复重刮、Windows 路径和 HTML 转义路径。受限写入使用现有文件快照与失败回滚。
- 快速、重新和中心的 URL 判站使用真实主机，避免论坛路径或查询参数中出现 `dlsite` 时误分流。单个及批量添加继续复用相同 DLsite 获取服务。
- 详情页重开、候选确认及完成反馈展示受限提示。文字使用主题动态颜色，提示图标使用语义颜色。

- 应用默认 HTTP 客户端的真实站点直连尝试超时；浏览器可达性与本机真实响应回放不能代替默认客户端端到端网络验收。
- 本轮未操作用户实际游戏库、已安装应用或账户登录态。五种模式的原生用例验证共享层，不等同于五种入口均执行过真实用户点击流程；详情重开与候选确认另有原生 UI 验证。

```powershell
flutter test --no-pub --concurrency=1 test/dlsite_parser_test.dart test/core/services/dlsite_service_test.dart test/core/services/scrape_apply_service_test.dart test/ui/pages/scraper/scrape_review_tokens_test.dart
```
