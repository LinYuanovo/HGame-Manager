# 存档管理

要使用存档扫描功能，需要先**标记游戏为「已玩」状态**（右键菜单的「添加游玩次数」或游戏详情页的「开始游玩」），并且本地确实有玩过该游戏。

![标记已玩](./images/image26.png)

## 扫描存档位置

1. 切换到「已玩」页面
2. 点击右上角的「扫描存档位置」按钮

![扫描存档位置](./images/image27.png)

3. 扫描完成后，进入游戏详情页会出现「存档」按钮

![存档按钮](./images/image28.png)

![存档路径](./images/image29.png)

::: warning 注意
存档扫描不依赖 `source_url.txt`，会尝试根据游戏目录中的 EXE 文件名、游戏标题及常见存档位置查找。请确认游戏目录正确且本地运行过游戏；扫描不保证 100% 成功，失败时可以**手动填写存档路径**。
:::

4. 如果扫描失败，手动填写存档路径(非必须)

![手动填写存档路径](./images/image35.png)

## 自动导入存档

当你有一些全CG/全图鉴存档时，将你想要导入的存档放在游戏的根目录下，并重命名为「**存档**」两个字，这样软件会自动识别并导入：

![重命名存档文件夹](./images/image30.png)

回到软件点击「存档管理」，可以看到自动导入的「导入存档」，并且能够进行「备份」「恢复」「上传至云端」（上传至云端必须在设置中填写 WebDAV）等一系列操作：

![存档管理](./images/image31.png)

## 下载全CG/全图鉴存档

在存档管理页面可以从2DFan进行搜索存档，如果有返回可以快速下载到本地进行替换等操作

![下载全CG/全图鉴存档](./images/image52.png)

## 备份与还原保护

存档备份保存在游戏的 `HGMDatas/backup/`。覆盖已有存档前，软件会先创建「还原前备份」；保护备份失败时停止还原。还原「还原前备份」本身时，也会先读入原备份内容，再保存当前存档。

还原前会校验压缩包和解压路径，拒绝损坏、包含链接或解压后超过 500 MiB 的备份。写盘过程中失败时，可能已替换部分文件，可使用已生成的保护备份恢复。
