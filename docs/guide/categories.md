# 分类管理

软件在刮削时会自动生成标签，但自动标签不一定符合你的需求。你可以通过「系列」功能自定义分类。

![分类页面](./images/image22.png)

## 创建自定义系列

1. 切换到「系列」
2. 点击右上角的「+」按钮

![创建系列](./images/image23.png)

## 将游戏移入系列

1. 回到「游戏」页面
2. 勾选想要归类的游戏
3. 右键点击游戏 → 选择「移入自定义系列」
4. 在弹窗中选择目标系列，点击确定

![勾选游戏](./images/image24.png)

![选择目标系列](./images/image25.png)
