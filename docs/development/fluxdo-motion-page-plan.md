# HGame 桌面动效逐页计划

本计划从 `codex/motion-loading` 的 `f02df84` 出发，描述用户在 Windows 上使用鼠标、键盘浏览游戏、查看图片和处理任务时应看到的反馈。各页设计与验收场景见下文，实施状态见文末。已有行为见[桌面动效逐页交接](motion-page-parity.md)。

## 动效节奏与参照

| 交互 | HGame 的设计约定 | FluxDO 参照 |
|---|---|---|
| 选择位置 | 页面在点击或按键时立即接收输入。共享选中标记用 `AppMotion.medium` 移到新位置，中途改变目标时从当前位置接续。 | [导航胶囊](https://github.com/Lingyan000/fluxdo/blob/185ccaa418dab8ea40192301e39065706192f866/lib/widgets/layout/adaptive_navigation.dart#L689) |
| 展开对象 | 封面、缩略图或可见卡片是运动起点。大幅展开用 `AppMotion.slow`，返回用 `AppMotion.medium`。内容提前按最终宽度排版，背景明暗、外壳和正文可以先后到位。 | [卡片展开为预览](https://github.com/Lingyan000/fluxdo/blob/185ccaa418dab8ea40192301e39065706192f866/lib/widgets/common/morphing_dialog_shell.dart#L12) · [图片返回](https://github.com/Lingyan000/fluxdo/blob/185ccaa418dab8ea40192301e39065706192f866/lib/pages/image_viewer_page.dart#L306) |
| 找到目标 | 用户主动查看结果时，先把目标移入视口，再给它一次短暂底色；建议停留约一秒。名称、图标和结果文字持续可读。 | [下载记录定位](https://github.com/Lingyan000/fluxdo/blob/185ccaa418dab8ea40192301e39065706192f866/lib/pages/download_list_page.dart#L49) · [指定设置项](https://github.com/Lingyan000/fluxdo/blob/185ccaa418dab8ea40192301e39065706192f866/lib/widgets/settings/settings_group_page.dart#L60) |
| 编辑与阅读 | 输入、选区、拖动与滚动跟随用户操作。实际运动的是候选、预览、工具条或匹配标记。正文搜索框和编辑器随时接受键盘输入。 | [搜索框与静态转场表面](https://github.com/Lingyan000/fluxdo/blob/185ccaa418dab8ea40192301e39065706192f866/lib/pages/search_page.dart#L879) |

在基线中，`AppMotion.fast`、`medium`、`slow` 分别为 140、220、300 毫秒。按压、着色、圆角和字体沿用 `AppMotion`、`AppTheme` 及现有设计令牌。系统开启减少动效时，共享标记直接落位，图片直接打开或关闭，结果直接滚到目标并用静态选中态说明位置。错误和进度的朗读与业务状态同步。用户切换窗口、调整大小或改变缩放后，按当前窗口重新确认落点。

## 主窗口与游戏库

| 页面或入口 | 触发与画面变化 | 验收场景 |
|---|---|---|
| 主窗口、侧栏与标题栏 | 点击导航，纵向标记从旧项移向新项，主内容按两项的可见顺序轻移并淡入。拖动侧栏宽度时标记贴住当前行。打开设置时，底层内容页继续表示当前位置。窗口按钮仅在各自范围内反馈。 | 重排侧栏后连续点三项，标记从途中转向最后一项。折叠后用键盘打开、关闭设置，焦点回到设置按钮，原页面仍被选中。 |
| 游戏库 | 首次出现时仅首屏卡片有限交错。切换海报和列表时，以同一游戏封面为视觉参照，名称在目标行稳定后接替。导入返回时，标出新增游戏；多个新增项用数量说明结果，以用户选中的游戏为定位目标。 | 在第二页选择一款游戏并切换视图，仍能认出它。连续输入搜索词时文字、光标和筛选即时更新。右键菜单、双击启动和多选使用各自已有的操作入口。 |
| 分类 | 标签和系列间切换时移动页签指示器。拖排时分类卡跟手，空位指示落点；松手后邻卡各归其位。双击或点击进入子页时，由实际触发入口的标签名接到子页标题。 | 用两个同名、不同 ID 的标签验证往返准确；在多选模式点击另一张卡时，只更新勾选与计数。 |
| 标签游戏 | 子页顶部保留来源标签名，列表在标题就位后出现。返回时恢复原分类列表的位置，短暂标出来源卡；来源已被删除时将焦点交给列表。 | 从视口底部的标签进入，滚动游戏列表、打开详情再逐层返回，分别回到原游戏和原标签。 |
| 收藏 | 游戏、分类两个页签各记住自己的位置。成功取消收藏后，对应卡片淡出，邻项填补空位，剩余数量同步更新；写入失败时在原卡显示原因。 | 连续取消相邻两项后，下一个可操作项获得焦点。移除最后一项时空态只出现一次，切到另一页签仍有正确的内容。 |
| 已玩 | 游玩记录刷新时，在当前行原位更新次数或时长。用户主动查看刚玩过的游戏时才定位；若排序位置改变，以稳定的游戏 ID 找到新位置。 | 正在浏览列表中部时有记录更新，视口保留。主动定位后高亮跟随正确游戏；游戏已被筛掉时显示可读结果。 |
| 通关 | 标记通关成功后，勾选或通关图标在所属游戏上出现一次。存档路径扫描以真实处理数更新工具栏；完成时保留扫描结果与选择。 | 对三款选中游戏扫描，其中一款已有存档路径。核对扫描数字、跳过数和选择范围；取消通关后焦点落到相邻条目。 |
| 已通关二级页 | `ClearedGamesPage` 的标题在本层保持稳定，进入游戏详情时沿用共享列表的来源标记；返回时依次恢复游戏和上一级入口。 | 从该页首项、末项分别进详情再按 Esc，确认一次只退出一层。空列表时焦点可到达返回入口。该页按现有挂载入口验收。 |
| 工具 | 新增或编辑完成后，目标工具卡局部显现并标出名称。双击时卡片压下、释放，启动错误在同一卡片旁给出。 | 创建两款同名工具，编辑第二款后只标出它。分别用右键编辑、双击启动，检查动作各执行一次。 |

## 详情、图片与阅读

| 页面或入口 | 触发与画面变化 | 验收场景 |
|---|---|---|
| 游戏详情 | 从海报打开时，可见封面的位置、比例和裁切逐步过渡到详情封面；标题与正文在最终宽度接替。返回时按游戏 ID 查找当前可见来源。无封面、键盘菜单或来源离屏时，详情表面在原位淡入或淡出，焦点回到入口。 | 用横图海报、竖图海报和无图行分别打开。飞行中按 Esc、修改封面后关闭、关闭时列表重排，各路径都只显示一张主封面，并恢复正确焦点。 |
| 大图查看器 | 点击缩略图时，图片从实际可见的裁切区域展开，遮罩先到位。滚轮缩放保留指针下的图像位置，平移跟手。翻图后，返程锚点改为当前图；来源仍可见时落回其缩略图，否则原位淡出。 | 从图 A 打开，翻到 B，放大平移后按 Esc，应回到 B 的缩略图。另测飞行中关闭、同一图片在正文和图集重复出现、来源滚出或图片丢失。关闭只退出查看器。 |
| 图片管理与封面选择 | 拖动缩略图时留出落点，松手后邻图补位。选择封面时标记从上一个封面交给新封面。保存时网格保持可见，确认后同步详情和列表封面。 | 同名文件来自两个目录时，标记跟随正确图片。分别执行取消、保存失败、成功后重新打开，核对顺序和封面。 |
| 简介、攻略与正文搜索 | 正文切换时标题保留，阅读区恢复各自位置。搜索命中先滚入视口，再突出文字；工具栏跨滚动阈值后局部出现。用户继续打字、选字或手动滚动时立即接管。 | 快速前后切换三个命中，最后命中保持可见。中文输入法组合期间保留候选与选区；关闭搜索后继续在当前位置阅读。 |
| 评分与评论 | 悬停只预示可选星级，键盘或点击确认后呈现实值。评论编辑器打开时焦点进入文本；保存成功后详情与列表在对应游戏上更新。 | 依次做悬停离开、取消编辑、保存。分别核对分值、评论、焦点，以及列表与详情两处入口的结果。 |
| Markdown 编辑与预览 | 编辑器和预览区按当前文段交接。返回编辑时恢复选区和滚动位置。点格式按钮后，只突出本次修改的文字或标记。 | 选中跨行中文后切预览再返回，选区、输入焦点、撤销记录保留。打开插图菜单再取消时，光标回到原处。 |
| 独立攻略浮窗 | 打开后在浮窗内恢复阅读位置，置顶图标在该窗口原位切换。点击正文图片时，以浮窗内图片为来源。缩放窗口时按新宽度安定排版。 | 主窗和浮窗显示不同阅读位置，用快捷键切换可见性，再切换置顶。核对正文位置、活动窗口和快捷键归属。 |

## 刮削、导入与备份

| 页面或入口 | 触发与画面变化 | 验收场景 |
|---|---|---|
| 刮削中心 | 扫描占位按任务行布局，首批结果接替占位。运行中更新单项状态和总进度。计划为失败计数提供「查看失败项」动作；触发后定位并突出具体任务，日志在用户主动跟随时滚到底部。 | 混合成功、失败、取消与多线程乱序完成。用户阅读旧日志期间视口稳定；点失败项后，文件夹、原因、当前任务三者一致。 |
| 详情快速刮削、重新刮削 | 回车或刷新后，输入框或刷新按钮立即进入忙碌态，已有详情仍可读。共享刮削处理返回已写入的结果后，再让变化的字段、标签或封面局部接替。 | 依次覆盖无变化、仅封面变化、来源失败和整理后目录发生变化。结果文字与真正完成的阶段一致，连续提交仅对应有效请求。 |
| 单个添加 | 切换来源时结果区接替，搜索框保留焦点。选中候选后，该行显示读取状态；确认添加成功后将目标游戏 ID 带回库中定位。 | 快速发起两次不同搜索且首次较晚返回，只显示当前搜索的结果。空结果、重试、已存在游戏分别显示对应终态。 |
| 批量添加 | 扫描、匹配、导入分别显示阶段和实际数量。行内图标随任务回执变化，用户可定位需要处理的文件夹。返回时先显示批次摘要，再由用户选择要查看的游戏。 | 使用同名但路径不同的目录，混合成功与失败。滚动到中部再接收进度，原行保持可读；查看失败项能找到准确的路径。 |
| 攻略搜索 | 切换站点或查询时更新候选区；获取选中攻略正文时保留候选，当前行显示等待。正文成功后将标题与摘要接到阅读区。 | 搜索 A 后立即选 B，A 的迟到结果不会覆盖 B。正文失败后重试同一候选，关闭时焦点回到详情入口。 |
| 本地存档管理 | 创建备份成功后定位新记录，编辑名称时保留对应行的位置。还原、删除的确认窗展示对象与动作，结束后在原行或邻行落焦。 | 检查备份为空、同名备份、取消还原、还原失败、删除最后一条。失败时仍能看见目标和下一次可用操作。 |
| 云端备份 | 首次读取按备份行占位，刷新保留已有表格。下载期间在目标行显示状态，完成后对应本地记录可识别；失败时保留云端目标与原因。 | 慢网下连续点击同一行，再关闭重开。核对操作归属、重复提交保护、本地结果和读屏提示。 |
| 目录移动与加入系列 | 选择系列时突出目标系列名。确认移动后先显示目录扫描，得到总量才显示确定进度；移动成功后按新路径恢复同一游戏的身份。 | 分别测试空目录、小目录和部分文件失败。结束时列表位置、路径及成功或失败文字与实际结果一致。 |
| 应用更新、内置网页验证 | 更新检查、下载、等待安装按阶段交接；下载量已知时进度跟随真值。网页验证显示宿主的打开、等待、结束和关闭状态，网页内容自行呈现。 | 下载断开时显示真实错误并可重试。网页验证取消和正常结束分别回到调用入口，原任务收到相应结果。 |

## 设置弹窗与配置编辑

设置从侧栏在当前内容之上打开。弹窗内分区指示器移动到目标，右侧内容在最终宽度接替。通过指定设置项进入时，先定位分区，再使目标行可见并标出名称；普通进入恢复该分区的阅读位置。

| 分区或子窗 | 触发与画面变化 | 验收场景 |
|---|---|---|
| 通用 | 修改主题、字体或海报显示选项时，可见样式按已选值更新，焦点留在控件。选择游戏库目录时，返回后在对应字段展示结果。 | 切换浅深主题并增大字体，当前设置名、选中值和焦点环持续可辨。取消目录选择时仍停在原字段。 |
| 管理 | 从配置行打开管理弹窗，标题承接该行名称。返回后短暂标出原行；需要重排的列表各自记住选中项。 | 用键盘依次打开两个管理子窗。关闭第二层后焦点应回到刚触发的那一行。 |
| 刮削 | 切换设置项或打开模式配置时，保留当前上下文；保存后将摘要写回原设置行。输入来源信息时，文本立即响应。 | 修改当前模式后切往其他分区再返回，摘要、实际保存值和选中模式一致。 |
| 网络 | 连接测试只在对应按钮和结果行显示测试中、成功、失败，错误文字保留到下次相关操作。 | 启动测试时继续选择文字；先失败再重试成功，最终状态对应最近一次有效测试。 |
| 备份 | 配置或验证备份服务时在相应行显示结果。执行还原前明确展示目标，结束后把焦点交回发起操作的控件。 | 取消确认、网络断开、成功完成分别走通；三种结果在减少动效模式下仍可辨认。 |
| 关于 | 检查更新时按钮切换为等待态，版本结果在该区域显示；打开更新窗沿用独立的下载阶段反馈。 | 快速开关设置后再次检查，版本文字和操作状态属于当前窗口。 |
| 侧栏管理 | 拖动时来源项浮起，目标槽位留空。释放后按新可见顺序布置侧栏，主窗口选中标记对准同一路由。 | 将当前页从顶部移到底部，再收起和展开侧栏，确认标记和键盘遍历顺序正确。 |
| 右键菜单管理 | 选中配置和菜单对象时突出当前行。可见性或顺序变化只在受影响的条目上呈现，保存后回到原设置行。 | 对不同上下文分别配置，再从对应游戏右键打开菜单，核对各自的项目与顺序。 |
| 重命名管理 | 编辑命名选项时，选中态跟随正在修改的配置。确认与取消退出后，设置行显示有效配置。 | 变更后取消，再打开确认原值；保存后重开，显示与实际持久化一致。 |
| 刮削模式配置 | 五个模式各用稳定身份。指示器移动到选定模式，规则正文局部替换，拖动和编辑期间保留输入焦点。 | 连续切三个模式，验证最后一个模式的选项、保存范围和焦点。 |
| 攻略热键 | 进入录制后为当前动作显示录制态。按下修饰键与主键后显示捕获组合，冲突或注册失败时在该项显示原因。 | 分别录入有效组合、取消和冲突组合。关闭后用实际生效的快捷键打开攻略浮窗。 |
| 元信息翻译 | 打开翻译配置时先落焦到可操作项。切换开关、修改配置和保存分别呈现选中、编辑和写入结果。 | 取消后保留旧值；保存后重新进入显示已生效值。切换主题时输入位置和控件可读性稳定。 |
| 标签录入 | 新标签在插入位置显现，移除后邻项补位；输入框持续接收下一个标签，重复词在原位置提示。 | 连续输入三个标签再撤销一项，同名标签的判定、键盘焦点与保存结果一致。 |

## 跨页验收顺序

1. **浏览与返回。** 从游戏库第二页海报进入详情，打开图片 A，翻到 B 后缩放，连续按两次 Esc。依次核对缩略图、游戏、滚动位置和键盘焦点。用列表模式、无图游戏和窗体缩放再走一遍。
2. **导入与定位。** 混合导入成功、重复和失败的目录，主动查看一项失败和一款新增游戏。按身份核对任务行、游戏卡以及各自的回程位置。
3. **任务与数据。** 从详情快速刮削、重新刮削、刮削中心、单个添加、批量添加分别触发更新。按入口实际支持的流程核对字段、封面、标签和目录整理后的反馈。以共享处理的回执作为显示成功的依据。
4. **可访问性与窗口。** 用键盘完成侧栏切页、打开设置子窗、阅读攻略、关闭大图。分别在正常和减少动效、浅深主题、窗口缩放时验证。记录焦点、读屏名称、目标对象和最终业务状态。
5. **原生观感。** 在 Windows 录制连续改向、展开中关闭、拖排与大图返回。以帧时间记录检查大图库和多任务下的输入响应，以逐帧回放检查封面重影、文字换行与错位归还。
