# 桌面动效逐页交接

目标分支 `codex/motion-loading`，起点 `366ee59`；只读参照 MovieDigger `feat/ui-motion-implementation` 的 `fa6a2d2`。本轮在现有加载、减少动效和状态保留机制上补交互，不改变业务流程。

| 页面或入口 | 对照交互与实施点 |
| --- | --- |
| 主窗口、侧栏、标题栏 | C01–C05/C12：方向切换、选中与系统按钮反馈；拖拽直接跟手 |
| 游戏库、已玩、通关、标签游戏、通关归档 | E01–E03/E08/E10：首屏、列表与海报、翻页、收藏标记使用共享列表 |
| 分类、收藏 | B06/C06/E10：标签页、分类卡、收藏与多选状态 |
| 工具页 | E01/E08：首屏工具卡、悬停、双击及右键菜单 |
| 游戏详情与图片查看 | D01/F03–F07：打开、翻图、缩放与拖动；只为离散操作做过渡 |
| 设置及管理、重命名、刮削配置、热键、翻译子窗 | C05/C06/D03–D06：分区选中、内容接替、弹窗和菜单 |
| 刮削中心、单个/批量导入 | G04–G06/H03：真实进度、状态、保留结果及操作互斥 |
| 攻略搜索、图片管理、存档、云备份 | D04/G04–G08：弹窗、列表等待、错误和重试 |
| Markdown、标签录入、移动、更新、网页验证、攻略浮窗 | C12/D04/G05：预览切换、菜单、确定与未知进度、独立窗口控制 |

刷新率：走当前窗口的 Flutter 帧回调，按经过时间计算，不用固定周期推进；装饰缩放和位移可有轻微回弹，透明度与任务进度不能越界。分别验证模拟帧间隔的轨迹和真实窗口表现，不将测试泵帧数当作显示器呈现帧率。

离线回归 278 项通过，Windows 浅深色 166 个界面状态通过并保存 166 张截图。截图位于 `build/motion-parity-1118/screens`，已抽查浅色游戏库、刮削中心、42% 更新进度、深色收藏和设置管理。更新窗口的版本号来自集成测试样本。

## 技术与复跑

- 参照源码：MovieDigger 的 `desktop/lib/ui/widgets/archive_button_motion.dart`（按下与释放分段），`desktop/lib/ui/controllers/archive_motion_policy.dart`（仅过滤装饰采样、保留原时间戳），`desktop/lib/ui/widgets/app_motion.dart`（短位移与独立透明度）。角色对应见该分支的 `docs/ui-motion-refactor/references/moviedigger-motion-inventory.md`。
- 本项目按窗口 `FlutterView.display.refreshRate` 获取自动采样上限。窗口可见但失焦仍保留动画；隐藏或系统减少动效时，相关有限过渡收束。进度条的语义值及时更新为 0–100 数字，不等待绘制完成。
- 原生探针在一个装饰控件上使用引擎自然帧。本机报告 **165.0 Hz**，800 ms 目标在 **800.606 ms** 收束，观察到 **110 个不同动画值**，终值 1.0。原始结果在 `build/motion-parity-1118/native-sampling.log`。混合刷新率跨屏、VRR、屏幕实际呈现 FPS 和重负载帧时间仍待硬件验收。
- 自动化验证覆盖 30、59.94、60、75、90、120、144、165、240 Hz 的采样上限，165 Hz 时间戳抖动与重复回调，以及减少动效、进度语义、深色键盘激活和禁用。轨迹终值测试覆盖其中七档，真实硬件验证为上述一档。
