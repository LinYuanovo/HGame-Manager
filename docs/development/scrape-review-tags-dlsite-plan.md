## 交互约定

批量刮削先收集候选资料，完成后进入单独确认表单。用户可逐项检查原游戏、候选标题、来源、简介、标签与图片，再决定保留或放弃本次候选资料。放弃保留游戏原有资料及文件。表单提供多选操作和指定文件夹移动，方便把需要继续处理的游戏集中整理。

自定义标签在游戏详情中直接编辑，保存时同步数据库和游戏目录元数据。补充用户指南，说明应用显示与 `HGMDatas/metadata.json` 的关系及重新扫描行为。

DLsite 用多个真实作品页面核对页面结构、简介和样例图片，再修复 URL 刮削与 ID/搜索导入共用的解析实现。
